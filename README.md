# Coffee-Sale-Analysis
**Project Overview**

This project analyzes coffee shop sales data collected between March 2024 and March 2025. The objective is to uncover customer purchasing behavior, product performance, revenue trends, and operational insights that can support business decision-making.

**Dataset Summary**
| Metric                     | Value               |
| -------------------------- | ------------------- |
| Total Transactions         | 3,547               |
| Total Revenue              | $112,246            |
| Menu Items                 | 8 Drinks            |
| Average Daily Transactions | 9.3                 |
| Best-Selling Drink         | Americano with Milk |
| Peak Revenue Hour          | 10 AM               |
| Best Revenue Month         | March 2025          |
| Lowest-Selling Drink       | Espresso            |
